# Security policy

## Reporting a vulnerability

Please **do not** open a public issue for a vulnerability that could let `damnyou` delete files outside a project root, bypass confirmation, follow a symlink, or execute an unintended command.

Report it privately instead, using GitHub's **"Report a vulnerability"** flow on the [Security tab](https://github.com/saif71/damnyou/security/advisories/new). Private reports go straight to the maintainers and let me coordinate a fix (and a CVE/GHSA) before any public disclosure.

If that channel is unavailable to you, open a minimal issue asking for a private contact method — without including exploit details.
